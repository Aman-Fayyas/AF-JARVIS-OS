# 1. THE FOUR FUNDAMENTAL PRINCIPLES

The entire architecture must follow these principles.

## PRINCIPLE 1 — EXTREMELY LOW RESOURCE USAGE

AF JARVIS OS must use the **lowest practical amount of RAM, CPU, storage, disk I/O, and background processing**.

RAM efficiency is one of the highest priorities of the project.

## PRINCIPLE 2 — LOCAL AI FIRST

JARVIS should normally use local AI rather than cloud AI.

## PRINCIPLE 3 — AI INFERENCE SHOULD NORMALLY RUN ON A SEPARATE DEVICE

The laptop running AF JARVIS OS should primarily be the:

**JARVIS CONTROL NODE**

Large-language-model inference should normally occur on a separate:

**JARVIS LOCAL AI NODE**

## PRINCIPLE 4 — CLOUD INTELLIGENCE ONLY WHEN WORTH USING

Cloud AI is optional secondary intelligence.

It should be used for tasks requiring substantially more intelligence, context, research ability, coding ability, multimodal capability, or reasoning than the local AI can practically provide.

Cloud AI must NOT automatically receive every normal conversation.

- Stability
